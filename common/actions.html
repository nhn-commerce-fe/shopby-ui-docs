ShopbySkin.actions

ShopbySkin.actions를 통해 접근할 수 있는 액션함수 가이드 입니다.

가이드에 앞서, 가이드 전반적으로 볼 수 있는 ShopbyContext에 대한 간단한 설명입니다.

ShopbyContext는 하나의 객체 타입을 뜻하는데 객체는 다음과 같은 프로퍼티를 가집니다.

일반적으로 ShopbySkin.actions로 접근할 수 있는 액션함수들은 ShopbyContext타입의 객체를 리턴합니다. 객체의 data 프로퍼티를 통해 데이터를 전달하게 됩니다.


// ShopbyContext
  - data : 응답데이터를 나타냅니다.
  - error : 에러가 발생한 경우 포함될 에러객체입니다.
  - isSuccess : API 통신 성공 여부입니다.
  - isError : API 통신 실패 여부입니다.
  - status : API응답 상태입니다.
  - payload : API를 호출할 때 전달했던 페이로드입니다.

* (params) => Promise<ShopbyContext> 형태의 함수는 특별한 설명이 없어도 API응답 데이터(또는 응답 데이터를 기반으로 재구성된 데이터)를 리턴하는 비동기 함수임을 나타냅니다.

* 즉, 각 액션 설명에 있는 XXXXX 이벤트를 통해 000데이터를 전달합니다. 라는 문구의 000데이터를 리턴합니다.

* 액션을 통해 API 호출시 API parameters의 Version, clientId, platform, language는 자동으로 설정되는 값입니다.

  • QUERY_ALL_CLAIMABLE_OPTIONS 이벤트를 통해 API 응답데이터의 originalOption, claimableOptions를 1차원 배열로 나열한 값을 전달합니다.

  • QUERY_IS_ACCOUNT_FOR_REFUND_NECESSARY 이벤트를 통해 해당 클레임 신청에 계좌정보가 필요한지에 대한 boolean 값을 전달합니다.

  • QUERY_CLAIM_SELECT_STATUS 이벤트를 통해 선택된 클레임상품(옵션)과 그 수량정보를 옵션 번호별로 구분하여 전달합니다.
