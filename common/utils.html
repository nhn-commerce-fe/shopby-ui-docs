ShopbySkin.utils

isSignIn () => void

  • html template의 보안상 위험요소를 제거한 뒤 리턴

파라미터 타입 설명

  • sb객체에 원하는 값을 저장할 때 사용

파라미터 타입 설명

키 값(함수일 경우 타입) 설명

  • 유저 정보입력란의 유효성 검사를 위해 사용됩니다. 회원정보수정, 회원가입 등에서 사용됩니다.

  • message는 유효한경우 유효메세지를, 유효하지않은경우 사유를 string으로 나타냅니다.
키 값(함수일 경우 타입) 설명

nickname ({ value, isDuplicated, isRequired }) => { message, isValid }

  • isValid는 유효성 여부를 boolean으로 나타냅니다.
  • message는 유효한경우 유효메세지를, 유효하지않은경우 사유를 string으로 나타냅니다.
키 값(함수일 경우 타입) 설명

  • 너비(width)에서 0 으로부터의 변위(offsetX)를 점수(maxRatingScore)에 비례한 값으로 변환
  • ex) width 100 , offsetX 30, maxRatingScore 5 인 경우 2를 리턴 - 상품리뷰의 별 점 주기 UI 표현에 유용합니다.
파라미터 타입 설명

maxRatingScore number (선택) 비례값. 해당값이 최대치로 가정된다. (default: 5)
useHalfScore number (선택) 리턴값을 0.5 단위로 나타낼것인지 여부

getStarSet ({ totalScore?, score }) => string[]

  • 별점을 어떻게 표시할것인지에 대한 함수
  • totalScore에 score를 별점으로 표현할 수 있게 문자열로 이루어진 배열을 리턴한다.
  • 0.5점단위의 별점을 표기하기에 사용된다.
  • ex) getStarSet({ score: 3.7 }) => ['full', 'full', 'full', 'half', 'empty'] 별점 3.5로 표시
파라미터 타입 설명

totalScore number (선택) 기준이 될 수 (default : 5)
