Handlebars 헬퍼 함수

HTML 템플릿에서 사용할 수 있는 빌트인 헬퍼 함수와 커스텀 헬퍼 함수들에 대해 설명합니다.

if

  • 인자가 true인 경우 true (false인 경우는 인자가 false, undefined, null, "", 0, []일때)

예시

{{#if secreted}}...{{/if}}
파라미터 타입 설명
x boolean 첫번째 인자

unless

  • 인자가 false인 경우 true (if 함수와 반대)

예시

{{#unless isLoading}}...{{/unless}}
파라미터 타입 설명
x boolean 첫번째 인자

each

  • 인자로 전달된 배열을 반복

예시

{{#each items}}...{{/each}}
파라미터 타입 설명
x array 첫번째 인자

with

  • 인자로 전달된 객체를 접근하여 내부 요소를 사용

예시

{{#with orderer}}
    ...
    {{ordererName}}
    {{ordererEmail}}
    ...
{{/with}}
파라미터 타입 설명
x object 첫번째 인자

lookup

  • 특정 상대 경로에 있는 변수를 접근

예시

{{#each people}}
   {{this}} lives in {{lookup ../cities @index}}
{{/each}}
파라미터 타입 설명
x string 첫번째 인자
y string 두번째 인자

log

  • 브라우저 콘솔 로그

예시

{{log "info logging" level="info"}}
파라미터 타입 설명
x string 첫번째 인자
level debug | info | warn | error 로그 형식 (없으면 default)

  • 배열인 첫번째 인자를 ,로 연결하여 문자로 반환

예시

 {{option categoryNo label selectedCategoryNo ''}}
파라미터 타입 설명
array array 첫번째 인자
key string 두번째 인자

maskingName

  • 이름의 중간을 *로 변환하여 마스킹 처리

예시

 {{maskingName issuerName}}
파라미터 타입 설명
value string 첫번째 인자

repeat

  • repeat으로 감싸져있는 항목들을 반복

예시

 {{repeat 4}}
파라미터 타입 설명
times number 첫번째 인자

dateFormat

  • 인자로 전달한 날짜 형식으로 반환

예시

 {{dateFormat startYmdt 'yyyy-mm-dd'}}
파라미터 타입 설명
date string 첫번째 인자
format string 두번째 인자

isWriter

  • 비밀글 여부 (registerType이 MEMBER이고 로그인한 memberNo가 registerNo와 같거나 modifierNo와 같으면 true)

예시

 {{isWriter memberNo registerType registerNo modifierNo title}}
파라미터 타입 설명
memberNo number 첫번째 인자
registerType string 두번째 인자
registerNo number 세번째 인자
modifierNo number 네번째 인자
title string 다섯번째 인자

isNewPost

  • 신규 게시글 여부 (작성일자가 24시간 이전이면 true)

예시

 {{#isNewPost registerYmdt}}...{{/isNewPost}}
파라미터 타입 설명
date string 첫번째 인자

isBestPost

  • 인기 게시글 여부 (조회수가 100이상이면 true)

예시

 {{#isBestPost viewCnt}}...{{/isBestPost}}
파라미터 타입 설명
count number 첫번째 인자

convertDateFormat

  • YYYY-MM-DD 형식으로 변환

예시

 {{convertDateFormat birthday}}
파라미터 타입 설명
value string 첫번째 인자

padStart

  • 최대 2글자로 인자의 좌측을 0으로 채워주는 함수 (padStart(2, '0'))

예시

 {{padStart minutes}}
파라미터 타입 설명
value number | string 첫번째 인자

커스텀 헬퍼 함수 등록하기

만약 여러분의 커스텀 헬퍼 함수를 등록하시려면 스크립트에 다음과 같이 작성해주세요.

<script>
const { Handlebars } = ShopbySkin;

Handlebars.registerHelper({
    formatStockCount(count) { // 헬퍼함수 명
        // 필요한 로직 작성
        return `타임세일! 얼마 안 남았어요! : ${count}`;
    },
});
</script>

...
<!-- 커스텀 헬퍼 함수 사용 예시 -->
{{ formatStockCount stockCount }}
