ShopbySkin.pageHelper

ShopbySkin.pageHelper는 페이지 또는 모달에서 필요한 동작들의 수행을 돕기 위해 제공하는 Shopby 전역 객체 입니다. 페이지 진입시 초기 값 설정 또는 모듈 데이터를 가져오는 등의 공통 기능을 제공하며 또한 각 helper에서 정의한 함수들도 사용할 수 있습니다. 아래 pageHelper 가이드는 페이지 별로 구분되어 있습니다.

helper 공통으로 제공하는 함수

  • 페이지 helper

    각 페이지에서 사용하는 helper로, 모달 helper 이외에 모든 helper가 여기에 속합니다.

    *사용 예시

    //초기 값 설정
helper.initialize();

//페이지내에 있는 모듈들의 내부 변수 조회
helper.getState();
  • 모달 helper

    모달에서 사용하는 helper로, helper명이 **ModalHelper인 helper들이 여기에 속합니다.

    *사용 예시

    //초기 값 설정
helper.initialize();

//모달 오픈
helper.openLayerModal({
	isFull: false,
	modalAddClass: 'search-zip-code',
	name: 'shipping-address-form-zip-code',
	title: '주소찾기',
});

//모달 종료 
helper.closeLayerModal({
	reason: 'DID_CLOSE',
	state: {} 
});
    함수파라미터설명
    initializeInitializeParam초기 값 설정
    (각 페이지별로 상이함)
    getState-모달 내부 변수 가져오는 함수
    openLayerModalOpenParam모달을 열때 사용
    closeLayerModalCloseParam모달을 닫을 때 사용하며 모달을 띄웠던 부모의 onClose 콜백이 실행됩니다.
    • OpenParam
    속성타입설명
    isFullboolean높이가 꽉 차게 설정할지 여부
    modalAddClassstring모달 상단 modal 클래스에 추가할 클래스명
    namestring레이어 모달 명.
    레이어 모달 태그에 설정한 name과 동일해야합니다.

    ex) pc/mo > modals > shipping-address-form.html
    하단에 추가한 레이어 모달 name 과 동일.

    <layer-modal-area type="title" name="shipping-address-form-zip-code" src="@modals/zip-code.html" title="주소찾기"></layer-modal-area>

    • CloseParam
    속성타입설명
    reasonDID_CLOSE | DID_SUBMIT모달 종료 이유 
    DID_CLOSE : 취소, 창 닫기 DID_SUBMIT : 확인
    stateany부모의 onClose 콜백 함수에 전달할 데이터
