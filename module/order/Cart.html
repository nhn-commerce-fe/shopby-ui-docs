장바구니

장바구니 페이지에서 노출되는 장바구니 모듈입니다.

URL: /pages/order/cart.html

관련 API : 🔗 장바구니 가져오기 API
모듈명: cart-products원본소스

장바구니 상품 목록 모듈입니다.

사용 가능 변수

변수명 타입 기본값 설명
isLoading boolean true 장바구니 가져오기 API 데이터 로딩 여부
isAllChecked boolean true 전체 선택 여부
accumulationUnit string - 관리자에서 설정한 쇼핑몰 적립금 단위
checkedCartNosAsString string - 현재 선택된 카트 번호를 문자열로 변환한 값
예) "90761,90762"
totalCount number 0 장바구니에 추가한 상품의 수
selectedCount number 0 선택한 상품의 수
checkedCartNos number[] [] 선택한 상품의 카트 번호
예) [90761, 90762]
cartDetail object - 장바구니 가져오기 API 응답 값과 동일
products array [] 장바구니 가져오기 API 응답 값 중 deliveryGroups 와 동일
모듈명: cart-order원본소스

장바구니 주문 정보 모듈입니다.

사용 가능 변수

변수명 타입 기본값 설명
accumulationUnit string 원 관리자에서 설정한 적립금 단위
totalCount number 0 장바구니에 추가한 상품의 수
selectedCount number 0 선택된 상품의 수
price Price - 장바구니 가져오기 API 응답 값 중 price 와 동일
(아래 타입 참조)

Price 타입

속성명 타입 기본값 설명
buyAmt number 0 구매금액 합
totalAmt number 0 총 구매금액 합(구매금액 합 + 총 선불배송비 합)
standardAmt number 0 정상금액(상품판매가 + 옵션추가금액) * 주문수량
discountAmt number 0 할인금액
totalDeliveryAmt number 0 총 배송비 합
totalPayOnDeliveryAmt number 0 총 착불배송비 합
totalPrePaidDeliveryAmt number 0 총 선불배송비 합
accumulationAmtWhenBuyConfirm number 0 구매확정 시 적립금 합
