거래명세서/간이영수증

주문 상세 페이지에서 노출되는 거래명세서/간이영수증 모듈입니다.

관련 API : 🔗 주문 상세 조회하기 API, 비회원 주문 상세 조회하기 API


거래명세서 URL: /pages/my/order-specification.html?orderNo={orderNo}

간이영수증 URL: /pages/my/simple-receipt.html?orderNo={orderNo}


※거래명세서: 지불 방식(payType)이 무통장입금(ACCOUNT), 전액할인(ZERO_PAY), 적립금 사용(ACCUMULATION)인 경우 사용
※간이영수증: 위의 경우를 제외한 나머지의 경우 사용

모듈명: order-specification원본소스

거래명세서/간이영수증 모듈입니다.

사용 가능 변수

변수명 타입 기본값 설명
orderDetail OrderDetail object 주문 상세 조회 API 응답 값과 동일
serviceBasicInfo ServiceBasicInfo object 쇼핑몰 기본정보
(아래 타입 참조)
flattenedOrderOptions FlattenedOrderOptions[] [] 주문 상세 조회하기 API, 비회원 주문 상세 조회하기 API 응답 데이터를 orderOptionsGroupByPartner 을 flatMap 하여 1차 배열로 만든 데이터
(아래 타입 참조)
totalDiscountAmt number 0 할인 금액
totalDeliveryAmt number 0 배송비
orderSpecificationEmptyCnt number 1 거래명세서 빈 공백 줄 개수

속성명 타입 기본값 설명
