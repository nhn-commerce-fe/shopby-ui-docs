주문 완료

주문 완료페이지 상단에 노출되는 주문 완료 모듈입니다.

URL: pages/order/order-complete.html?deliverable={deliverable}&orderSheetNo={orderSheetNo}&orderNo={orderNo}&PayType={PayType}&result={result}

관련 API : 🔗 주문 상세 조회하기 API, 비회원 주문 상세 조회하기 API
모듈명: order-complete-top원본소스

주문 완료 상단 모듈입니다

사용 가능 변수

변수명 타입 기본값 설명
orderNo string - 주문번호
ordererName string - 주문자명
모듈명: order-product-options원본소스

주문내역 모듈입니다.

속성

속성명 타입 기본값 설명
shopby-deliverable N - 배송여부

shopby-modal-title-prefix string - 클레임상태 앞에서 2글자
클레임 상세 모달 상단 제목에 사용

shopby-delivery-type string - 배송 타입
shopby-pay-type string - 결제타입
shopby-order-status string - 주문상태
shopby-claim-nos string - 클레임 번호를 나열한 값.
클레임 철회시 validation 확인할 때 사용
shopby-order-option-no number - 주문옵션번호
shopby-claim-no number - 클레임 번호

shopby-product-no number - 상품번호
