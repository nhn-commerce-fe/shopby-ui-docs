변수명 타입 기본값 설명

noticeBoard BoardsCategories[] [] 몰 정보 조회하기API 응답 값에서 boardsCategories에서 boardId 가 notice 인 값 (게시판 카테고리 목록)

slider SliderIdState - 슬라이더 고유 id
