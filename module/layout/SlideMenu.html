슬라이드 메뉴

모바일 공통 상단 메뉴 버튼을 클릭시 노출되는 슬라이드 메뉴 모듈입니다.

관련 API : 🔗 몰 정보 조회 API
모듈명: slide-menu원본소스

슬라이드 메뉴 모듈입니다.

속성

속성명 타입 기본값 설명
shopby-category-no number - (필수)카테고리 번호
하위 카테고리가 있는 경우 하위 카테고리 리스트 열기/닫기 이벤트를 위해 사용한다.

사용 가능 변수

변수명 타입 기본값 설명
isSignedIn boolean false 로그인 여부
multiLevelCategories Category[] [] 몰정보 조회 API 응답 중 categories.multiLevelCategories와 동일 (카테고리 정보)
(아래 타입 참조)
boardsCategories BoardsCategories[] [] 몰정보 조회 API 응답 중의 boardsCategories와 동일한 데이터 (게시판 정보)
(아래 타입 참조)
hasEvents boolean false 기획전 존재 여부

Category 타입

속성명 타입 기본값 설명
categoryNo number - 카테고리 번호
depth number - 카테고리 depth
label string - 카테고리명
count number 0 카테고리 상품 수
children array [] 하위 카테고리 목록
CategoryChildren 타입과 동일한 데이터

BoardsCategories 타입

속성명 타입 기본값 설명
used boolean false 게시판 사용 여부
boardNo number - 게시판 번호
boardName string - 게시판 이름
커스텀 핸들바 더 알아보기
:query 속성 더 알아보기
