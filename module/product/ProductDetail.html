상품상세

상품상세 페이지에서 노출되는 상품상세 모듈입니다.

URL: /pages/product/product-detail.html?productNo={productNo}

관련 API : 🔗 상품상세 조회 API, 상품문의 목록 조회 API, 관련상품 조회 API, 상품평 목록 조회 API

상품 상세 메인 이미지 모듈입니다.
