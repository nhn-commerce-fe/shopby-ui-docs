배송지 등록/수정 폼

배송지 등록/수정 폼에 사용되는 모듈입니다.

가이드에서는 데이터 노출 형태를 보여주기 위해 `수정`모드로 출력됩니다.

모듈명: my-shipping-address-basic-information원본소스
배송지 기본정보

사용 가능 변수

변수명 타입 기본값 설명
addressName string - 배송지 이름
receiverName string - 받으시는 분
모듈명: my-shipping-address-address-information원본소스
배송지 주소 정보

사용 가능 변수

변수명 타입 기본값 설명
zipCode string - 우편번호
address string - 주소
detailAddress string - 상세 주소
모듈명: my-shipping-address-contact-information원본소스
배송지 연락처 정보

사용 가능 변수

변수명 타입 기본값 설명
mobileNumber string - 휴대폰 번호
phoneNumber string - 전화번호
모듈명: my-shipping-address-extra-information원본소스
배송지 추가 정보

사용 가능 변수

변수명 타입 기본값 설명
willBeSavedAsDefaultAddress boolean false 기본 배송지 여부
모듈명: my-shipping-address-form-btns원본소스
배송지 등록/수정 버튼 그룹

사용 가능 변수

변수명 타입 기본값 설명
isRegisterMode boolean true 등록 여부
false인 경우 수정
커스텀 핸들바 더 알아보기
