상품 문의 상세

상품 문의 상세페이지에서 노출되는 상품 문의 상세 모듈입니다.

URL: /pages/my/product-inquiry-detail.html?productNo={productNo}&inquiryNo={inquiryNo}&boardIdx={boardIdx}

관련 API : 🔗 상품 문의 조회 API
모듈명: product-inquiry-detail원본소스

상품 문의 상세 모듈입니다.

속성

속성명 타입 기본값 설명
product-no:query number - (필수)query string 중 productNo 값
상품 번호
inquiry-no:query number - (필수)query string 중 inquiryNo 값
상품 문의 번호
boardIdx number - query string 중 boardIdx 값
상품 문의 게시글 index 번호

사용 가능 변수

변수명 타입 기본값 설명
replied boolean false 답변 여부
type PRODUCT | DELIVERY | CANCEL | RETURN | EXCHANGE | REFUND | OTHER - 상품문의 타입
productInquiryDisplayType 상품 | 배송 | 취소 | 반품 | 교환 | 환불 | 기타 - 상품문의 타입 한글명
title string - 문의 제목
content string - 문의 내용
imageUrl string - 상품 이미지 url
productName string - 상품명
registerName string - 작성자 명
registerYmdt string - 상품문의 등록 일자
answers Answers[] [] 답변 내용
(아래 타입 참조)

Answers 타입

속성명 타입 기본값 설명
secreted boolean false 상품문의 답변 비밀글 여부
administrator boolean false 상품문의 답변 관리자 여부
registerYmdt string - 상품문의 답변 등록 일자
updateYmdt string - 상품문의 답변 수정 일
partnerName string - 상품문의 답변자 파트너인 경우, 파트너명
nickName string - 상품문의 답변자 닉네임
title string - 상품문의 답변 제목
content string - 상품문의 답변 내용
memberId string - 상품문의 답변 작성자 아이디
inquiryNo number - 상품문의 답변 번호
커스텀 핸들바 더 알아보기
:query 속성 더 알아보기
