속성

속성명 타입 기본값 설명
shopby-tab-value string - 탭의 값

사용 가능 변수

변수명 타입 기본값 설명
currentTab string ALL 현재 클릭되어 있는 탭의 값
모듈명: my-orders원본소스

주문 목록 모듈입니다.

속성

속성명 타입 기본값 설명
start-ymd:query string - query string 중 startYmd
기간조회 시작일
end-ymd:query string - query string 중 endYmd
조회 종료일
page-size
page-size:query		 number
string		 20
pageSize		 query string 중 pageSize
페이지 사이즈
page-number
page-number:query		 number
string		 1
pageNumber		 query string 중 pageNumber
페이지 번호
claim-type:query string - query string 중 claimType
클레임 타입
date-type:query string - query string 중 dateType
데이트 타입
(오늘:td, 7일:7d, 15일:15d, 1개월:1md, 3개월:3md, 1년:1y)
default-page-size string - 리스트의 기본 page size
pair-key string - 더보기에서 사용하는 key
shopby-delivery-uri string - 배송 uri
shopby-delivery-type string - 배송 타입
shopby-order-option-count string - 주문 상품 옵션의 수
shopby-order-next-action-type string - 해당 주문건에 대해 다음에 할 수 있는 작업타입
shopby-claim-no string - 클레임 번호
shopby-modal-title-prefix string - 클레임상태 앞에서 2글자
클레임 상세 모달 상단 제목에 사용
shopby-order-option-no string - 주문옵션번호
shopby-pay-type string - 결제타입
shopby-order-status string - 주문상태
shopby-claim-nos string - 클레임 번호를 나열한 값.
클레임 철회시 유효성 확인할 때 사용
shopby-order-no string - 주문번호
shopby-product-no string - 상품번호
shopby-deliverable Y | N N 배송여부

사용 가능 변수

변수명 타입 기본값 설명
isLoading boolean true API 응답값을 받기 전에 true
currentTab string ALL shopby-tab-value 에 넣은 값
totalCount number 0 조회 결과 총 주문 수
pagination Pagination - 페이지네이션
(아래 타입 참조)
myOrders MyOrders[] [] 주문내역
myOrdersGroupByYmd MyOrdersGroupByYmd[] [] 주문날짜로 그룹핑한 주문리스트
