관련 API : 🔗 몰 정보 조회 API, 게시판 설정 조회 API, 회원 정보 조회 API, 주문 상태별 주문 수량 및 금액 조회 API, 주문 상태별 주문 수량 조회 API, 내 쿠폰 요약 정보 조회 API, 적립금 요약 조회 API, 회원이 좋아하는 상품 수 조회 API, 이전주문 수량 조회 API
모듈명: my-menu원본소스

마이페이지 메뉴 모듈입니다.

사용 가능 변수

변수명 타입 기본값 설명
menuTitle string - 현재 마이페이지 메뉴명
boardConfig BoardConfig - 게시판 설정 조회하기 API API 응답 결과 중 boardConfigs에서 현재 접근한 게시판에 대한 설정 정보
(아래 타입 참조)
accumulationConfig AccumulationConfig - 몰 적립금 설정 API 응답 중 accumulationConfig와 동일 (적립금 설정)
(아래 타입 참조)

BoardConfig 타입

속성명 타입 기본값 설명
canAttach boolean false 첨부파일 사용 여부
canPostBySecret boolean false 비밀글 작성 여부
canPostByMember boolean false 회원 작성가능 여부
guestPostingUsed boolean false 비회원 작성가능 여부

(아래 타입 참조)

Profile 타입

속성명 타입 기본값 설명
memberType MALL | SYNCID | OPENID - 회원 아이디
MALL: 일반 회원, SYNCID: 연동형 회원, OPENID: 간편로그인 회원
memberName string - 회원 이름
memberId string - 회원 아이디
providerType string - 마지막 연동 SNS 구분
memberTypeLabel string - 회원 구분별 타입명
memberType이 MALL 이거나 providerType이 NCPSTORE이면 쇼핑몰
이외에는 providerType값과 동일
