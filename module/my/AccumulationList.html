적립금

적립금 페이지에서 노출되는 적립금 모듈입니다.

URL: /pages/my/accumulation-list.html?startYmd={startYmd}&dateType={dateType}

관련 API : 🔗 적립금 이력 조회 API
모듈명: my-accumulation원본소스

적립금 현황 모듈입니다.

사용 가능 변수

변수명 타입 기본값 설명
totalAvailableAmt number 0 사용가능한 총 적립금액
totalExpireAmt number 0 만료조회 총 적립금액
accumulationConfig AccumulationConfig - 몰 적립금 설정 API 응답 중 accumulationConfig와 동일 (적립금 설정)
(아래 타입 참조)

AccumulationConfig 타입

속성명 타입 기본값 설명
accumulationName string - 적립금명
accumulationUnit string - 적립금 단위
모듈명: my-accumulation-list원본소스
적립금 목록
