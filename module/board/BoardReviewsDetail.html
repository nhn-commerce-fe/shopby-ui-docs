상품후기 상세 모달

전체 상품 후기 게시판 페이지에 상품 후기 상세 모달에서 노출되는 상품후기 상세 모듈입니다.

관련 API : 🔗 상품평 게시판 목록 조회 API, 상품 기준 상품평 게시판 목록 조회 API
모듈명: board-reviews-detail원본소스

상품후기 상세 모듈입니다.

사용 가능 변수

변수명 타입 기본값 설명
activeImg string - 선택한 이미지
review Review - 상품평 가져오기 API 응답 결과와 동일 (상품평)
(아래 타입 참조)
reviewConfig ReviewConfig - 게시판 설정 조회하기 API API 응답 값 중 productReviewConfig와 동일
(아래 타입 참조)

Review 타입

속성명 타입 기본값 설명
registerName string - 작성자 명
registerYmdt string - 등록일
fileUrls string[] [] 파일 URL 리스트
starSet (full | half | empty)[] [] 별표 점수 리스트
full:1점, half:0.5점, empty: 0점
productNo number - 상품 번호
reviewNo number - 상품평 번호
productTotalCount number 0 상품평 총 개수
orderedOption OrderedOption - 주문 옵션 정보
(아래 타입 참조)

OrderedOption 타입

속성명 타입 기본값 설명
optionName string - 옵션명
optionValue string - 옵션값

ReviewConfig 타입

속성명 타입 기본값 설명
replyUsed boolean false 답글작성 가능 여부
guestPostingUsed boolean false 비회원 작성가능 여부
attachmentUsed boolean false 첨부파일 사용 여부
name string - 게시판 이름
