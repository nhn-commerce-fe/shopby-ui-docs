게시판 상세

게시판 상세페이지에서 노출되는 게시판 상세 모듈입니다.

URL: /pages/board/post-detail.html?boardId={boardId}&articleNo={articleNo}

관련 API : 🔗 게시글 상세 조회 API
모듈명: article-view (deprecated)원본소스

게시판 상세 모듈입니다.

속성

속성명 타입 기본값 설명
article-no:query number - (필수)query string 중 articleNo 값
게시글 번호

allow-iframe-board-nos string - (선택) iframe을 허용할 게시판 번호 목록 (쉼표 구분, '*'로 모든 게시판 허용)
