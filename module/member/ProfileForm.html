회원정보 폼

회원가입, 회원정보 수정 페이지에서 노출되는 회원정보 폼 모듈입니다.

URL: (회원정보수정) /pages/my/modify-member.html, (회원가입) /pages/sign-up/sign-up-form.html

관련 API : 🔗 회원정보 조회 API, 회원 프로필 등록 API, 회원정보 추가항목 조회 API
